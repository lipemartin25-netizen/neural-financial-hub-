# SQL-Auditor

**Descrição:** Automatiza, supervisiona e audita processos SQL completos: executa queries seguras, valida resultados, faz backups, gera logs de auditoria e monitora performance. Torna operações de banco de dados robustas e seguras com detecção de erros, índices otimizados e relatórios automáticos.

**Triggers:** sql, query, banco de dados, auditoria sql, executar query, otimizar sql, backup banco, monitorar db, auditar query

**Modos:** 
- Manual: pede confirmação antes de executar.
- Auto: para skills confiáveis.

**Exemplos de uso:**
- "Execute esta query no PostgreSQL e audite os resultados"
- "Otimize e supervise o processo de migração SQL"
- "Faça backup auditado da tabela users"

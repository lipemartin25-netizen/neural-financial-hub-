# Skill: repo-bootstrap

## Quando Usar
Utilizar ao inicializar um repositório vazio, configurar estrutura básica de monorepositório ou estabelecer dependências de fundação.

## Procedimento
1. Verificar ferramentas instaladas no ambiente (Python, Node/npm, Java/Android SDK, Git).
2. Criar estrutura de diretórios respeitando a arquitetura definida.
3. Gerar arquivos base de configuração (`.gitignore`, `.env.example`, `package.json`, `requirements.txt`).
4. Escrever testes de fumaça básicos (smoke tests) para validar que os esqueletos executam.
5. Executar os comandos de validação local e registrar evidências objetivas e bloqueios encontrados.
